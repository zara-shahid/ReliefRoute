Project Overview

ReliefRoute is an intelligent disaster relief coordination platform that combines a multi-agent AI pipeline, a Vehicle Routing Problem (VRP) with Time Windows solver, and a live tactical operations dashboard. It automates the process of ingesting raw disaster field reports, classifying urgency, placing sites on a map, optimizing vehicle dispatch routes, and enabling AI-powered command queries — all in real time.

Vercel + Supabase

System Architecture — The 4-Step Pipeline

Every submitted disaster report flows through a fully automated 4-step agent pipeline:

Step 1
Intake
Parse raw field report, extract site name, coordinates, resources needed
Step 2
Prioritize
Score urgency (0–100), assign severity, set time window
Step 3
VRP Solve
OR-Tools optimizes vehicle routes for all pending sites
Step 4
Dispatch
Save routes to DB, update fleet status, notify dashboard

Key Features

Demo Walkthrough

Setup — Before Starting

Live Demo (Recommended): Use the deployed production URLs. No local setup needed. Frontend: relief-route-pink.vercel.app | API: relief-route-h537.vercel.app/api
Local Demo: Start Django on port 8000 and Next.js on port 3000 before running the demo script.

Step-by-Step Demo Flow

  1. Open the dashboard
    Navigate to relief-route-pink.vercel.app. The landing page shows an animated 3D globe with a tactical command interface. Click Enter Command or navigate to the Dashboard.
  2. Tour the Tactical Map tab
    Point out the Leaflet map with color-coded disaster site markers (red = critical, orange = high, yellow = moderate, green = low). Vehicle depots are shown as blue pins. Existing routes appear as colored polylines.
  3. Show the Operations panel
    Click the Operations tab. Demonstrate the Site list (name, severity, resource needed, urgency score) and Fleet list (vehicle name, capacity, driver, status). Add a new site manually to show the form.
  4. Submit disaster reports via the pipeline
    Run the demo script from the command line (local) or trigger reports via the API directly.
    Each report auto-triggers the 4-step AI pipeline: parse → score → VRP → dispatch.
  5. Click SOLVE VRP
    Press the [ SOLVE VRP ] button in the top-right header. The system recalculates optimal routes for all pending sites using OR-Tools. The map updates with new route polylines within seconds.
  6. Demonstrate Dispatch AI
    Go to Dispatch AI tab. Type natural language queries (see suggested queries below). The LLaMA 3.3-70B agent responds using live database context — route summaries, urgency scores, ETAs.
  7. Run Fleet Simulator
    Go to Fleet Sim tab. Click play to animate vehicles moving along their optimized routes in real time. The top status bar updates distance and ETA counters live.

After each report, refresh the Tactical Map at localhost:3000 — the new site marker and re-optimized routes appear automatically within 5 seconds.

Scripted Disaster Scenarios

The following 10 scenarios are pre-written for dramatic narrative effect: starting moderate, escalating to critical mass incidents, and closing with logistical challenges. Submit them in order for maximum impact.

1
Gas Leak — Residential Area, Haight & Masonic, San Francisco
Moderate · 4/10
Gas leak reported at the corner of Haight Street and Masonic Avenue. Approximately 45 residents evacuated from nearby apartments. Need immediate supply of emergency respirators and first aid kits. The leak has been contained but residents cannot return home.
Expected pipeline output: Site created with urgency score ~40, 1 vehicle route assigned for respirators + first aid delivery.
2
School Roof Collapse — Children Trapped, Lincoln Elementary
High · 7/10
URGENT: Partial roof collapse at Lincoln Elementary School on 23rd Avenue. Estimated 60 children and 8 staff members sheltering in the gymnasium. Structural integrity compromised. Require rescue gear, medical supplies, and emergency food rations. No confirmed injuries yet but situation is deteriorating.
Expected pipeline output: High urgency score ~70, prioritized in VRP — vehicle dispatched before lower-severity sites.
3
Flash Flood — 120 Residents Stranded, Sunset District
High · 8/10
Flash flooding in the Sunset District near Irving Street and 9th Avenue. Street-level flooding 1.5 meters deep. Around 120 residents stranded on upper floors. Need inflatable rescue boats, water purification units, and emergency food for 72 hours. Three elderly residents cannot be evacuated without medical assistance.
Expected pipeline output: Urgency ~80, multi-stop route — rescue boats + food + medical on same vehicle or split across two.
4
Chemical Spill — 90 Trapped, Bay Bridge Approach
Critical · 9/10
CRITICAL EMERGENCY: Chemical tanker overturned on Bay Bridge approach ramp near Fremont Street. Unknown industrial solvent leaking. 200-meter exclusion zone established. Approximately 90 people trapped in vehicles. Require hazmat suits, oxygen tanks, medical triage units, and decontamination equipment. Two confirmed injuries. Fumes spreading — time critical.
Expected pipeline output: Urgency ~92, inserted at top of VRP route, earliest time window, dedicated vehicle assignment.
5
Elderly Care Facility — Power Outage, Life Support at Risk
Moderate · 6/10
Power outage at Sunset Valley Care Home on Taraval Street. 80 elderly residents housed, 12 on life-support or oxygen-dependent equipment. Backup generator failed 2 hours ago. Need portable generators, emergency oxygen supplies, and medical staff immediately. Temperature inside dropping.
Expected pipeline output: Despite "moderate" severity label, AI escalates urgency due to life-support context. Score ~65, high priority routing.

API Reference
Endpoint Method Description
/api/sites/ GET / POST List all disaster sites or create a new one manually
/api/vehicles/ GET / POST List all fleet vehicles or add a new vehicle
/api/routes/ GET Retrieve all current optimized vehicle routes with stops and instructions

/api/agent/chat/ POST Send a question to the Dispatch AI agent. Body: {"message": "..."}
/api/agent/pipeline/ POST Submit a raw disaster field report. Body: {"report": "..."} — runs full 4-step pipeline

Demo Day Checklist

Before the Demo

  • Open relief-route-pink.vercel.app in browser (test that it loads)
  • Verify relief-route-h537.vercel.app/api/sites/ returns JSON
  • Confirm Supabase DB has data (run seed.py locally if needed)
  • Confirm at least 2 vehicles exist in the Operations → Fleet panel
  • Open Dispatch AI tab and send a test message to verify Groq API key works
  • Zoom browser to 100% and open in fullscreen for the map view

During the Demo

  • Walk through all 4 dashboard tabs (Tactical Map, Operations, Dispatch AI, Fleet Sim)
  • Submit at least Scenario 4 (Chemical Spill) or Scenario 6 (Building Collapse) live
  • Click SOLVE VRP and show the map updating in real time
  • Ask the Dispatch AI: "Which site is highest priority and why?"
  • Run Fleet Simulator to show animated vehicle movement

Talking Points

  • AI pipeline runs in < 5 seconds per report end-to-end
  • VRP solver uses OR-Tools — same library used by Google Maps Logistics
  • Dispatch AI is grounded on live DB, not hallucinating — it only knows what's deployed
  • Fully serverless — no persistent server, auto-scales with Vercel
  • Supabase PostgreSQL — persistent data across sessions and deployments
Tip: For the most dramatic effect, submit Scenarios 1–3 first (low/moderate), then submit Scenario 6 (SEVERITY 10 — building collapse) and click SOLVE VRP. The map visually re-routes all vehicles to prioritize the new critical incident.
